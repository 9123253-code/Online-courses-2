# Реєстрація на курси

## Опис проєкту

Цей проєкт є веб-формою для реєстрації користувача на курси.

Форма містить поля для введення імені, електронної пошти та пароля. Для зручності користувача реалізована перевірка правильності введених даних.

## Функціональність

У проєкті реалізовано:

- введення імені користувача;
- введення електронної пошти;
- введення пароля;
- перевірку правильності імені;
- перевірку формату електронної пошти;
- перевірку мінімальної довжини пароля;
- визначення сили пароля;
- підсвічування правильних та неправильних полів;
- виведення повідомлень про помилки;
- кнопку «Зареєструватися»;
- кнопку «Очистити»;
- ефекти наведення та натискання для полів і кнопок.

## Використані технології

Для створення проєкту використано:

- HTML — для структури веб-сторінки;
- CSS — для оформлення форми та створення ефектів;
- JavaScript — для перевірки введених даних та взаємодії з користувачем.

## Валідація даних

Для імені перевіряється наявність щонайменше 2 символів.

Для електронної пошти перевіряється наявність символів `@` та `.`.

Для пароля встановлена мінімальна довжина 8 символів. Також визначається його сила залежно від наявності малих і великих літер, цифр та спеціальних символів.

## Запуск проєкту

Для запуску проєкту не потрібно встановлювати додаткове програмне забезпечення.

1. Завантажити або клонувати репозиторій.
2. Відкрити папку проєкту.
3. Відкрити HTML-файл у будь-якому сучасному браузері.
4. Заповнити форму та перевірити її роботу.
